# Coding Standards

This document records the coding standards for this directory scope.

## Comments

- Rule: Document all Rust types, enum variants, and fields, including private and tuple fields.
  - Example: `/// This pool supplies database connections.`
- Rule: Follow ASD-STE100 for Rust doc comments.
  - Example: `/// Read the configuration file.`
- Rule: Give each Rust module a one- or two-sentence description.
  - Example: `//! This module checks database access.`
